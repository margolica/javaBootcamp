# Java Bootcamp – День 00
## Обзор

Добро пожаловать на День 00 Java Bootcamp! Эта сессия познакомит вас с решением бизнес-задач с использованием основных конструкций Java. Упражнения разработаны для того, чтобы помочь вам понять основные функции Java, включая примитивные типы, циклы, условия и операции ввода/вывода. Каждая задача структурирована так, чтобы имитировать реальные сценарии, способствуя развитию навыков решения проблем и логического мышления.

---

## Общие Правила

1. **Версия Java**: Используйте Java 1.8 для всех задач.
2. **Стандарты кода**: Следуйте [Кодексу Конвенций Java от Oracle](https://www.oracle.com/java/technologies/javase/codeconventions-namingconventions.html).
3. **Комментарии**: Избегайте комментариев в коде для поддержания читаемости.
4. **Сдача**: Решения должны храниться в вашем репозитории Git.
5. **Сотрудничество**: Спрашивайте соседей о помощи, если это необходимо.
6. **Вывод**: Используйте `System.out` для всех выводов.
7. **Ограничения**: Пользовательские методы и классы запрещены, если не указано иное.

## Упражнения

### **Упражнение 00 – Сумма Цифр**

- **Цель**: Вычислить сумму цифр шестизначного целого числа.
- **Ввод**: Заранее заданное шестизначное число в программе.
- **Вывод**: Сумма цифр.
- **Пример**:
    
    javascript
    

- ```javascript
    $ java Программа
      42
    ```
    

---

### **Упражнение 01 – Действительно Простое Число**

- **Цель**: Определить, является ли число простым, и подсчитать количество итераций, необходимых для проверки.
- **Ввод**: Число, введенное с клавиатуры.
- **Вывод**: Является ли число простым и количество итераций.
- **Специальные Случаи**: Для 0, 1 или отрицательных чисел вывести "Неверный аргумент" и выйти с кодом -1.
- **Пример**:
    
    javascript
    

- ```javascript
    $ java Программа
    -> 113
       true 10
    ```
    

---

### **Упражнение 02 – Бесконечная Последовательность (или нет?)**

- **Цель**: Подсчитать числа в последовательности, сумма цифр которых является простым числом.
- **Ввод**: Последовательность натуральных чисел, заканчивающаяся на 42.
- **Вывод**: Количество чисел, соответствующих критериям.
- **Пример**:
    
    javascript
    

- ```javascript
    $ java Программа
    -> 198131
    -> 12901212
    -> 42
       Количество запросов на кофе – 2
    ```
    

---

### **Упражнение 03 – Немного Статистики**

- **Цель**: Визуализировать прогресс студентов за неделю с помощью гистограммы.
- **Ввод**: Оценки за тесты за неделю (5 оценок в неделю, до 18 недель).
- **Вывод**: Гистограмма, показывающая минимальную оценку за каждую неделю.
- **Специальные Случаи**: Если данные введены в неправильном порядке, вывести "Неверный аргумент" и выйти с кодом -1.
- **Пример**:
    
    javascript
    

- ```javascript
    $ java Программа
    -> Неделя 1
    -> 4 5 2 4 2
    -> Неделя 2
    -> 7 7 7 7 6
    -> 42
    Неделя 1 ==>
    Неделя 2 ======>
    ```
